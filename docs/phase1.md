# フェーズ1 手触りの試作

目的は「打つ」という操作が気持ちいいかを確かめることです。ここが面白くなければ、見た目を豪華にしても遊ばれません。

**次に進む条件**：知人5人に遊んでもらい、「もう一回」と言われる。

## 入っているもの

- ネオン・ルーフトップのアリーナ（台、浮遊プラットフォーム、夜景のビル）をパーツで自動生成
- 練習モード：壁打ち、Bot（やさしい・ふつう・つよい）
- サーバーが決める軌道でボールが飛ぶ。ボールの速さに応じて軌跡の色が白→青→紫に変わる
- 打つタイミングの判定と、それに応じた返球
  - PERFECT：速い球、ゲージ+2、画面が揺れて少しズームする
  - GOOD：ふつうの球、ゲージ+1
  - あまい：遅くて高い、相手が打ちやすい球
  - MISS：失点
- 早すぎ・遅すぎたときは「◯ms 早い／遅い」と表示する（調整用）
- 7点先取、6-6からはデュース、3ゲーム中2ゲーム先取、サーブは2本ずつ交代
- PC（マウス・キーボード）、スマホ（「打つ」ボタン）、コントローラー（R2・右スティック）に対応

## まだ入っていないもの（後のフェーズ）

- 2人のオンライン対戦（フェーズ2）
- 特殊能力（フェーズ3。ゲージはたまるが、まだ使えない）
- ラケットを振るアニメーション、本番の効果音（今は Roblox 標準の音を仮に使用）
- ランク戦、マッチング、保存（フェーズ4）

## 遊び方（Studio）

1. README の手順で `rojo serve` して Studio から Connect
2. Play（F5）
3. メニューから「壁打ち」を選ぶ
4. 左右に動いてボールの来る位置に立ち、ボールが自分のラケットの高さに来た瞬間にクリック（またはスペース）

## 試してほしいこと

| 確かめること | 見るところ |
| --- | --- |
| PERFECT を狙って出せるか | 壁打ちで10回中何回 PERFECT が出るか |
| 早い・遅いが自分でわかるか | 「◯ms 早い／遅い」の表示と自分の感覚が合うか |
| 球が見やすいか | 軌跡と、台に落ちる影で、どこに来るか読めるか |
| Bot の強さ | やさしい＝勝てる、ふつう＝いい勝負、つよい＝負けることが多い、になっているか |
| スマホで遊べるか | 「打つ」ボタンの位置と大きさ、移動しながら押せるか |

## 調整するときに触る数値（`src/shared/Rally/Config.luau`）

| 数値 | 今の値 | 意味 |
| --- | --- | --- |
| `Timing.perfect` / `good` / `weak` | 0.06 / 0.14 / 0.24 秒 | 判定の時間幅。広げると簡単になる |
| `Shots.*.duration` | 0.8〜1.35 秒 | 球が相手に届くまでの時間。短いほど速い |
| `Shots.*.arc1` / `arc2` | 1.1〜3.4 | 球の山の高さ |
| `Reach` | 3.2 studs | 立っている位置から届く横の距離 |
| `IgnoreEarlierThan` | 0.45 秒 | これより早いボタンは無視する（連打で失点しないように） |
| `MaxReportedLag` | 0.35 秒 | 通信の遅れとして認める上限（不正対策） |

Bot の強さは `src/shared/Rally/Bot.luau` の `Profiles`（タイミングのずれ、空振りの確率、移動速度、コースの散らし方）で調整します。
