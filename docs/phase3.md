# フェーズ3 特殊能力

8種類の能力を、リフトゲージを使って試合で使えるようにしました。

**次に進む条件**：どの能力も勝率が45〜55%に収まる。

## 遊び方

1. メニューの「能力を2つ選ぶ」で2つ選ぶ（3つ目を押すと、古いほうが外れる）
2. 試合を始める（壁打ち・Bot・オンラインのどれでも使える）
3. リフトゲージがたまると、能力が自動で発動する（ボタンは押さなくてよい）

- 2つの能力は交互に出る。次に出るほうの枠に「次」と表示される
- **ショット系**：ゲージが足りた状態で打ち返すと、その球にかかる
- **すぐ発動する系**：ゲージが足りると、役に立つ場面で出る（条件は `Abilities.Auto` と `Match.autoUse`）
- Bot も同じ決まりで能力を使う
- 能力は1ラリーにつき1人1回まで。使った瞬間に、相手の画面にも能力名と色が大きく出る
- 試合開始時に、相手が持ってきた2つの能力が表示される

## 能力の一覧（調整後の数値）

ゲージは打ち返すたびに+1、PERFECTなら+2、最大10。

| 能力 | タイプ | ゲージ | 効果 | 対処法 |
| --- | --- | --- | --- | --- |
| カーブショット | 攻撃 | 3 | 次の返球が途中で横に曲がる（最大3.2スタッド） | 曲がる先を読んで先に動く |
| ライトニングスマッシュ | 攻撃 | 5 | 次の返球が1.6倍速。相手の打てる時間の幅が65%になる | 早めの位置取り |
| ファントム | かく乱 | 4 | 次の返球が3つに分身する | 台に影が落ちるのは本物だけ |
| ブラインドバウンド | かく乱 | 3 | 次の返球が、弾むまで透明 | 台の影と弾む音で読む |
| タイムスロー | 防御 | 4 | 自分に来る球が2秒間半分の速さになり、打つ時間の幅も1.3倍 | 使わせた後に攻める |
| リフトバリア | 防御 | 8 | 向かってくる球を取り逃したら、1回だけ自動で打ち返す。返球はとても甘い（相手の打てる幅が2.3倍） | 甘い返球を決める |
| グラビティウェル | 妨害 | 3 | 相手の移動速度が4秒間半分になる | 動かずにすむ位置で待つ |
| ブリンク | 移動 | 2 | 球に届かないとき、球のほうへ最大6スタッド瞬間移動 | ― |

仕様書から変えた点（バランス調整の結果）：

- リフトバリア：ゲージ6→8。張った時に向かってきている球にだけ効く（ラリー中ずっと残らない）。返球を打ちやすくした
- グラビティウェル：ゲージ4→3、効果を「3秒間30%減」→「4秒間半減」
- スマッシュ：相手の打てる幅を「半分」→「65%」
- タイムスロー：遅くなった球は打つ時間の幅も1.3倍
- 共通ルールを追加：あまい球（Weak）を受けた側は、打つ時間の幅が1.4倍。甘い球を決めやすくするため

## バランスの測り方

```bash
lune run tools/balance 80
```

Bot「ふつう」同士に能力を1つずつ持たせ、全組み合わせを左右入れ替えて80試合ずつ戦わせて、能力ごとの勝率を出します。いまの結果（各640試合、誤差はおよそ±2%）：

| 能力 | 勝率 |
| --- | --- |
| リフトバリア | 54.8% |
| ブラインドバウンド | 51.7% |
| ライトニングスマッシュ | 51.1% |
| （能力なし） | 50.8% |
| カーブショット | 50.0% |
| ファントム | 49.1% |
| タイムスロー | 48.4% |
| グラビティウェル | 48.0% |
| ブリンク | 46.1% |

すべて45〜55%に入っています。ただしこれは Bot 同士の結果です。Bot は人より移動が正確なので、移動を邪魔する・助ける能力（グラビティウェル、ブリンク）は、人が使うともっと強くなる可能性があります。人どうしのテストで確かめてください。

Bot がどれだけ能力にだまされるか（ファントムで取り逃す確率、ブラインドでのタイミングのずれ、カーブを読むまでの時間）は `src/shared/Rally/Bot.luau` の `CONFUSION` と `Abilities.Tuning.Curve.revealAt` で決めています。

## テスト

| ファイル | 内容 |

| `tests/Abilities.spec.luau` | 各能力の効果、ゲージ、1ラリー1回、バリアの発動、Bot が全能力を使うこと |
| `tests/Smoke.spec.luau` | Roblox の代わりの仮の環境で、画面（Hud）、ボール描画（BallView）、アリーナを動かす。サーバーとクライアントを同時に動かして、Bot と1試合やり切る。オンラインで2人が組まれ、片方が抜けると残った人が勝つ |
| `tests/FakeRoblox.luau` | 上のテスト用の、Roblox エンジンの簡単な代わり |
