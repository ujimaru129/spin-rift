# フェーズ2 オンライン対戦

同じサーバーにいる2人で1対1の試合ができるようにし、通信の遅れがあっても「打ったのに空振りになった」と感じないようにします。

**次に進む条件**：往復200ミリ秒の通信遅れをわざと加えても、「当たったのに空振りした」と感じない。

## 入っているもの

- メニューの「オンライン対戦（このサーバーの人と）」で待ち行列に入り、2人そろうと専用のアリーナで試合が始まる
- 2人目は反対側（マゼンタ）に立ち、カメラも自分の側から見る
- 試合中に相手が抜けたら、残った人の勝ち（「相手が退出しました」と表示）
- 右上に通信の往復時間（ms）を表示。150msを超えると黄色、250msを超えると赤
- 練習モード（壁打ち・Bot）はフェーズ1のまま使える

## ラグ対策の仕組み

| 対策 | 内容 | 場所 |
| --- | --- | --- |
| 共通の時計 | 軌道は「サーバー時刻の何秒に、どこを通るか」で決まる。全員が同じサーバー時刻で描くので、自分の画面でラケットに来た瞬間が、サーバーでも同じ瞬間になる | `Trajectory`、`BallView` |
| 打った時刻を送る | 端末は「サーバー時刻で何秒に打ったか」を送る。サーバーは届いた時刻ではなく、この時刻で判定する（ただし0.35秒より古い申告や未来の時刻は補正する） | `Judge.trustedSwingTime` |
| 失点の判定を待つ | ボールが通り過ぎても、すぐには失点にしない。まだ届いていない「間に合ったスイング」を0.35秒待つ | `Config.MissGrace` |
| 自分の位置を送る | サーバーから見たキャラの位置は少し古い。端末が送った位置を、通信の遅れの間に歩ける範囲内なら採用する | `Judge.trustedPlayerZ` |
| 球の追いつき | 相手が打った球は少し遅れて届く。いきなり先に飛ばさず、0.2秒かけて本来の位置に追いつかせる | `BallView` の `CATCH_UP` |

自動テストでは、往復200msの遅れの中で「自分の画面でタイミングが合っていたスイング」が60回続けて失点にならないことを確かめています。`MissGrace` を0にするとこのテストは失敗します。

## 遊び方（Studio で2人対戦を試す）

1. README の手順で `rojo serve` して Studio から Connect
2. 上のメニューの「テスト」タブ →「クライアントとサーバー」で、プレイヤー数を **2** にして「開始」
3. 開いた2つのウィンドウの両方で「オンライン対戦（このサーバーの人と）」を押す

### 通信の遅れを加えて試す

1. サーバー側のウィンドウ（または編集中の Studio）のエクスプローラーで `ReplicatedStorage` を選ぶ
2. プロパティの「属性」に、名前 `DebugLagMs`、種類「数値」で `200` を追加する
3. 試合中のメッセージに、往復で200msの遅れが加わる（右上の表示にも足される）

属性を消すか0にすると元に戻ります。Studio の設定（ネットワーク →「受信レプリケーションの遅延」）でも遅れを加えられます。

## 試してほしいこと

| 確かめること | 見るところ |
| --- | --- |
| 2人で試合が最後までできるか | 7点先取、デュース、3ゲーム中2ゲーム先取、サーブ交代 |
| 遅れ200msで空振り感がないか | `DebugLagMs` を200にして、ちょうどのタイミングで PERFECT や GOOD が出るか |
| 相手の球の見え方 | 相手が打った直後に球がワープしたように見えないか |
| 途中で抜けたとき | 残った人に「WIN!」と「相手が退出しました」が出るか |
